# Tags Taxonomy

Tags são metadados visuais nos cards do hub. Cada ideia recebe **1-3 tags** atribuídas pelo scout/curator no momento da análise. Ficam visíveis ANTES de clicar pra expandir o card.

## Lista fechada (pode evoluir, mas só com decisão explícita)

| Tag | Slug | Quando aplicar |
|---|---|---|
| 🇧🇷 Tropicalização forte | `tropicalizacao-forte` | Adaptação BR é o diferencial central da ideia (ex: precisa de Pix nativo, WhatsApp-first, integração com Receita Federal) |
| 💰 Alto ROI | `alto-roi` | Mercado grande + preço alto + CAC baixo. Evidência: comparáveis com >$1M ARR <2 anos |
| ⚡ Dev rápido | `dev-rapido` | MVP entregável em ≤4 semanas por solo dev. Stack conhecido, sem fricção técnica grave |
| 📈 Boa adesão | `boa-adesao` | Sinais de virality, share orgânico, ou demanda reprimida (filas de espera, lista de waitlist grande) |
| 🌎 Geral | `geral` | Ideia útil mas sem ponto forte particular — entra na pool sem destaque |
| 🎯 Must Have validado | `must-have-validado` | Dor classificada Must Have COM evidência sólida na fonte |
| 🏗️ Defensável | `defensavel` | Tem barreira de entrada (network effect, dado proprietário, regulação) |
| 🤖 IA-core | `ia-core` | IA é o produto, não enfeite. Sem IA, ideia não existe |
| 🌱 Nordeste-fit | `nordeste-fit` | Resolve dor regional específica (ex: agricultura familiar, turismo NE, gestão pública municipal) |
| 🔁 Padrão recorrente | `padrao-recorrente` | Apareceu em 3+ fontes ou em batches diferentes (alto sinal) |

## Regras

- **Máx 3 tags por ideia**. Mais que isso vira ruído visual.
- **Sempre 1 tag de origem**: `tropicalizacao-forte`, `geral`, ou `nordeste-fit`.
- **Cores no hub**: cada tag tem cor própria — palette discreta, sem neon. Usar paleta de `project_decisions.md` (off-white #FAFAF7, cores muted).
- **Tag falsa** = problema sério. Curator pode rebaixar tag se análise posterior mostrar que não se sustenta.

## Tags NÃO permitidas (slop alert)

- ~~"Game-changing"~~
- ~~"Revolutionary"~~
- ~~"Unicorn potential"~~
- ~~"AI-powered"~~ (todo mundo é AI-powered agora, é ruído)
- ~~"Disrupt"~~

Curator deve falhar a análise com erro explícito se tentar usar termo banido.
